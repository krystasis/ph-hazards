## bot検知の強度・サイト構造
- nginx。`ETag` と `Last-Modified` を返す → 条件付き GET で、変更が無ければ 304(本文なし)。
- 証明書の中間 CA(GlobalSign RSA OV SSL CA 2018)をサーバーが送ってこない。検証は切らず、中間証明書を同梱。
- 行 = 1 地震。1 列目のリンク先(速報ページ)のファイル名が ID になる。
  `2026_0921_0058_B1.html` = UTC 00:58 の地震の速報 1 版。同じ分に別の地震があると秒まで付く(`2026_0920_201041`)。
  `_B1` → `_B2` は版の差し替えなので、接尾辞を外した部分を event_id にして上書きする。
- M1.7 程度の小さな地震まで載る(USGS 系の世界版サイトとの違い)。

## 過去分(月別ページ)— 2026-09-21 追記
- `EQLatest-Monthly/<年>/<年>_<月名>.html`。2018-01 から先月まで、トップページからリンクされている。1 か月 0.5〜4MB。
- 構造は当月ページと同じで、同じ解析が通る(2018-01 と 2026-08 で実測)。
- **リンク先のファイル名は ID に使えない。** 2018-01 では 8 件の別々の地震が同じリンク(`2017_1231_1556_B1.html`)を共有していた。
  event_id は「発生時刻(分)+ 緯度 + 経度」から作る。
- ページは月の全件を載せているので、月ごとのファイルは毎回その内容で置き換える(訂正・削除に追従)。
  行数が 5% を超えて減ったら途中で切れたページとみなし、書かずに赤にする。
- 取り込みは `collector/backfill_eq.py` で 1 回だけ。月ごとに 1 リクエスト、20 秒空ける。済んだ月は二度と取らない。
